# Small Wins Club — post media

Slide images for [@the.small.wins.club](https://instagram.com/the.small.wins.club).

This repo exists for one reason: **Buffer's API does not accept file uploads.** Media has to be
reachable at a public URL, so approved slides get pushed here and referenced by their
`raw.githubusercontent.com` link when the post is scheduled.

Images only. Captions, templates and the build pipeline live in the private EA_TVK repo
under `projects/social-content-engine/`.

Nothing lands here until it has been reviewed and approved, so this repo only ever contains
slides that are already on their way to being published.
